Это сложная задача по нескольким причинам. Важно сразу прояснить ограничения:

1.  **Конфиденциальность данных:** Wildberries и Ozon **не публикуют** данные о стоимости аренды конкретного помещения и доходности существующих ПВЗ в открытом доступе (на картах для клиентов). Эта информация является коммерческой тайной владельца ПВЗ.
2.  **Источник данных для обучения:** Чтобы получить данные вида `[координаты, этаж, цена бизнеса, доходность]`, вам нужно парсить не карты WB/Ozon, а **сайты объявлений о продаже готового бизнеса** (например, Avito, Cian, Юла в разделе "Готовый бизнес -> ПВЗ"). Именно там продавцы указывают прибыль и стоимость.
3.  **Защита от ботов:** И маркетплейсы, и доски объявлений используют очень серьезную защиту (Cloudflare, капчи, динамические токены).

Ниже я приведу пример архитектуры и кода на Python, который решает задачу **сбора координат существующих ПВЗ** (через API маркетплейсов) и объясню, как подойти к сбору финансовых данных.

### Часть 1. Парсинг координат ПВЗ (WB/Ozon)

Самый надежный способ собрать координаты — использовать внутренние API, к которым обращаются их карты.

*Примечание: API часто меняются, код может потребовать актуализации заголовков.*

#### Установка библиотек
```bash
pip install requests pandas
```

#### Пример кода (Сбор координат Wildberries)
WB отдает данные чанками или по регионам. Ниже упрощенный пример запроса к их публичному API для карт.

```python
import requests
import pandas as pd
import json

def get_wb_points():
    # URL часто меняется, его нужно отлавливать через DevTools (Network) на сайте wb.ru/geo
    url = "https://static-basket-01.wb.ru/vol0/data/all-poo-fr-v2.json"
    
    headers = {
        "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/120.0.0.0 Safari/537.36",
    }

    try:
        response = requests.get(url, headers=headers)
        data = response.json()
        
        points = []
        for item in data:
            # Структура JSON может отличаться, нужно смотреть актуальный ответ
            # Обычно это список словарей
            point = {
                "type": "WB",
                "id": item.get("id"),
                "lat": item.get("coordinates", [0,0])[0],
                "lon": item.get("coordinates", [0,0])[1],
                "address": item.get("address"),
                "work_time": item.get("workTime")
            }
            points.append(point)
            
        return pd.DataFrame(points)
    except Exception as e:
        print(f"Ошибка при парсинге WB: {e}")
        return pd.DataFrame()

# Запуск
df_wb = get_wb_points()
print(f"Найдено ПВЗ WB: {len(df_wb)}")
df_wb.to_csv("wb_points.csv", index=False)
```

### Часть 2. Парсинг финансовых данных (Avito/Cian)

Для получения `стоимости` и `доходности` вам нужно парсить объявления. **Обычный `requests` здесь не сработает** из-за защиты. Нужно использовать `Selenium` или `Playwright` с хорошими прокси.

Ниже пример логики на **Playwright** (более современный аналог Selenium), который заходит на сайт и ищет данные.

#### Установка
```bash
pip install playwright
playwright install
```

#### Пример кода (Скелет парсера объявлений)

```python
import asyncio
from playwright.async_api import async_playwright
import pandas as pd
import re

async def parse_business_listings():
    data = []
    
    async with async_playwright() as p:
        # Запускаем браузер (headless=False, чтобы видеть, если вылезет капча)
        browser = await p.chromium.launch(headless=False)
        page = await browser.new_page()
        
        # Пример ссылки (нужно подставить реальный URL поиска по запросу "ПВЗ Wildberries")
        # ВНИМАНИЕ: Сайты блокируют автоматические переходы. Нужны задержки и прокси.
        search_url = "https://www.avito.ru/all/gotoviy_biznes?q=пвз+wildberries" 
        
        await page.goto(search_url, timeout=60000)
        await page.wait_for_timeout(5000) # Ждем прогрузки

        # Логика сбора ссылок на объявления
        listings = await page.locator('[data-marker="item"]').all()
        
        for listing in listings[:5]: # Для теста берем первые 5
            try:
                # Парсим цену из превью
                price_text = await listing.locator('[itemprop="price"]').get_attribute("content")
                
                # Кликаем на объявление, чтобы получить детали (в идеале открывать в новой вкладке)
                # Здесь упрощенно парсим заголовок и описание
                title = await listing.locator('[itemprop="name"]').inner_text()
                
                # Извлечение координат и этажа - это сложная задача, 
                # так как на Авито координаты скрыты в карте, а этаж в тексте.
                # Приходится использовать регулярные выражения по описанию.
                
                item_data = {
                    "title": title,
                    "price": price_text,
                    # "profit": ... # Нужно парсить описание (regexp)
                    # "floor": ... # Нужно парсить описание
                }
                data.append(item_data)
                
            except Exception as e:
                print(f"Ошибка парсинга элемента: {e}")

        await browser.close()
    
    return pd.DataFrame(data)
```

### Как объединить данные для нейросети

Так как вы не получите официальные данные о прибыли всех точек, вам придется действовать так:

1.  **Собрать датасет "Продажа" (Обучающая выборка):**
    *   Спарсить 1000-5000 объявлений о продаже ПВЗ.
    *   Из описания вытащить: `Адрес`, `Прибыль`, `Стоимость`, `Этаж`.
    *   Геокодировать адрес (преобразовать ул. Ленина 1 в Lat/Lon) через API Яндекс.Карт или DaData.

2.  **Собрать датасет "Окружение" (Признаки/Features):**
    *   Для каждой точки из шага 1 собрать данные об окружении (это то, на чем будет учиться нейросеть):
        *   Количество конкурентов в радиусе 500м (из парсера Части 1).
        *   Плотность жилой застройки (можно взять из OpenStreetMap).
        *   Проходимость (косвенно через количество коммерческих объектов рядом).

### Итоговый план действий для вас

1.  Напишите скрипт на `requests`, который выкачивает все **существующие** точки WB и Ozon (как в примере 1). Это даст вам карту конкурентов.
2.  Используйте `Playwright` для сбора данных о **продающихся** ПВЗ с досок объявлений.
3.  Напишите скрипт с регулярными выражениями (Regex), который будет искать в тексте объявлений слова: *"прибыль XXX"*, *"чистыми XXX"*, *"этаж X"*.
4.  Преобразуйте адреса из объявлений в координаты.
5.  Объедините всё в CSV: `Lat, Lon, Floor, Competitors_Radius_300m, Price, Monthly_Profit`.

**Важное предостережение:** Не пытайтесь парсить Ozon/WB/Avito в промышленных масштабах с одного IP-адреса. Вас заблокируют мгновенно. Используйте ротируемые прокси (mobile proxies) и большие задержки между запросами (`time.sleep(random.randint(5, 15))`).
